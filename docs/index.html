云迹CloudTrace

把位置选在地图上，把移动交给线路和摇杆。

开源的 Android 位置模拟应用：地图选点、线路巡航、悬浮摇杆，无需 Root。

下载最新版本 查看源码

位置模拟

地图点选、地点搜索、经纬度输入，普通 / 卫星 / 夜间地图。

线路巡航

按目标公里数与配速自动移动，支持横向变道与防雷同收尾。

悬浮摇杆

步行 / 跑步 / 骑行档位，跨应用控制移动方向。

数据留在本机

位置、线路与历史只保存在设备上，不收集个人信息。

安装要求

  • Android 8.0 及以上（minSdk 27），仅提供 arm64-v8a 安装包。
  • 首次使用需在系统开发者选项中将「云迹」设为模拟位置信息应用。
  • 使用悬浮摇杆需要授予悬浮窗权限。

更新与校验

  • 应用内更新使用 ECDSA 签名清单；清单地址：/update/stable.json。
  • APK 与更新清单均可从本页和 GitHub Releases 获取，请核对来源。
